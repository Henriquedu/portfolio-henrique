### Dashboard de gestão de incidentes

Painel para análise de volume, SLA, MTTR, FCR e recorrência de chamados. O objetivo é transformar registros operacionais em uma visão clara dos gargalos e das oportunidades de melhoria.

## Como executar localmente

Clone o repositório:

```bash
git clone https://github.com/Henriquedu/portfolio-henrique.git
```

Entre na pasta:

```bash
cd portfolio-henrique
```

Instale as dependências:

```bash
pnpm install
```

Inicie o servidor de desenvolvimento:

```bash
pnpm dev
```

Para gerar a versão de produção:

```bash
pnpm build
```

O currículo utilizado no site está em:

```text
client/public/curriculo-henrique-eduardo.pdf
```
